# Pull Request Policy

1. สมาชิกต้องสร้าง Branch ก่อนเริ่มพัฒนา

2. ห้าม Push Code ลง main โดยตรง

3. หลังพัฒนาเสร็จต้อง Push Branch ขึ้น GitHub

4. ต้องสร้าง Pull Request ก่อน Merge

5. ต้องมีสมาชิกตรวจสอบ Code ก่อน Merge

6. Feature Branch Merge เข้า develop

7. develop Merge เข้า main เมื่อพร้อม Release
